# nsclc_synth — synthetic multimodal NSCLC immunotherapy benchmark (v2)

This package rebuilds the synthetic cohort used in Chapter 4. It answers reviewer comments 13 and 14. The data are **synthetic**: no row is a real patient.

## What it contains

| Path | Purpose |
|---|---|
| `nsclc_synth/config.py` | Every parameter of the data-generating process. These are the knobs that Scenarios A–F will vary: prevalence, sample size, missingness, distribution shift and noise. |
| `nsclc_synth/generator.py` | The data-generating process. It also holds `RELATIONSHIPS`, the documented list of every simulated relationship with its justification and source. |
| `scripts/validate_synthetic.py` | Validates the synthetic data against published statistics and the real TCGA-LUSC data. |
| `outputs/cohort_n300_seed42/` | The v2 analysis cohort: `patients.csv`, three embedding files (`.npy`), `config.json`, and the hidden latent truth, which is never used as model input. |
| `outputs/validation/` | Validation tables (CSV), figures and `summary.json`. |
| `nsclc_synth/systemic_pipeline.py` | Preprocessing for the systemic/clinical stream. The same code runs on synthetic and real data. All statistics are fitted on training data only. |
| `scripts/real_tcga_systemic.py` | Comment 2. Runs the pipeline on real TCGA-LUSC data and writes a data-quality log, missingness tables, a schema-coverage table, and an overall-survival proxy check. |
| `outputs/real_tcga/` | Results of the real-data run. |
| `scripts/real_tcga_molecular.py` | Comments 2 and 14. Adds real TMB, EGFR/STK11/KRAS/KEAP1/TP53 status and smoking (from open-access GDC files) to the real patient table, runs the same systemic pipeline on the extended vector, repeats the survival proxy check, and compares the synthetic cohort with the real molecular data. |
| `scripts/real_tcga_pathology.py` | Comment 3. Label-free diagnostics for the real Phikon slide embeddings: run summary, effective dimensionality, slide identification, spatial coherence and linkage to real records. |
| `outputs/real_tcga_gdc/` | Derived real data from the Colab notebook: mutation features, exposure, slide-level embeddings and the run log. Patch-level embeddings are regenerated by the notebook. |
| `outputs/real_tcga_molecular/`, `outputs/real_tcga_pathology/` | Results of the two scripts above (thesis Tables 4.2a to 4.2d, Figures 4.1a and 4.1b). |

## Reproduce

```
pip install -r requirements.txt
python scripts/validate_synthetic.py --tcga path/to/TCGA_LUSC_clinical_clean.xlsx --out outputs/validation
python scripts/real_tcga_systemic.py --tcga path/to/TCGA_LUSC_clinical_clean.xlsx --out outputs/real_tcga
python scripts/real_tcga_molecular.py
python scripts/real_tcga_pathology.py --fm path/to/tcga_lusc_real_outputs   # folder from colab/TCGA_LUSC_real_data.ipynb
```

Fixed seeds:
- `seed=42` for the analysis cohort.
- `seed=1` for the 50,000-patient reference cohort.
- Seeds 1000–1199 for the 200 replicate cohorts.
- `loading_seed=2026` for the fixed embedding "foundation model".
- The intercept-calibration population uses seed 987654321.

## Design in one paragraph

Six hidden factors drive everything that is observed:
- immune activation
- tumour burden
- systemic inflammation
- autoimmune susceptibility
- toxicity severity
- unobservable response determinants

The observed variables are clinical data, pathology (PD-L1, TILs, necrosis and a 512-dimension embedding), radiology (volume, shape, texture and a 128-dimension embedding) and systemic data (TMB, NLR, LDH, CRP, albumin, ctDNA, EGFR, STK11 and a 64-dimension embedding). They are generated from these factors. Outcomes depend on the factors through logistic models.

Immune activation is shared by response and toxicity. That reproduces the published positive association between irAEs and benefit. TMB is generated independently of PD-L1, as published.

Outcome intercepts are solved once on a 200,000-patient unshifted reference population. Requested prevalences therefore hold in the source population, while shifted cohorts drift naturally.

## Experiment programme (comments 4–12 and 17–20)

```
python scripts/run_experiments.py --exp main --reps 20        # also: missing ablation prevalence noise samplesize
python scripts/run_explainability.py
python scripts/summarise_results.py                            # writes outputs/results (tables, figures, scorecard)
```

- Raw results, one row per replicate, are in `outputs/experiments/`. Explainability outputs are in `outputs/explainability/`. Thesis-ready tables and figures are in `outputs/results/`.
- `PRESPECIFIED_SUCCESS_CRITERIA.md` was written before any results were viewed. `outputs/results/table_scorecard.csv` scores it.
- `colab/TCGA_LUSC_real_data.ipynb` covers comments 2 and 3 in one run. It needs no account or manifest: it pulls the open-access TCGA-LUSC masked somatic MAFs from the GDC API and derives TMB and EGFR/STK11/KRAS/KEAP1/TP53 status, adds smoking exposure, then downloads diagnostic slides one at a time and embeds tissue patches with the Phikon pathology foundation model (UNI optional). Open it in Google Colab with a T4 GPU and choose Run all.
- `colab/run_foundation_model_tcga.py` is the command-line version of the slide step, for any CUDA machine.
- Process notes:
  - A 5-replicate pilot of the main experiment ran first. Its results were kept and are part of the 20 replicates, because the model specification was not changed after the pilot.
  - `missing.csv` had misaligned rows from an early version of the results writer. `scripts/repair_missing_csv.py` repaired it, and the original is kept as `missing.csv.bak`.
